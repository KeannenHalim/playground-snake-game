# 🐍 Snake Game

A simple **Snake Game** built as a playground project to practice programming fundamentals, game logic, and input handling.

This project is intentionally kept small and readable, making it suitable for learning, experimentation, and extension.

---

## 🎮 Features

* Classic snake movement (up, down, left, right)
* Food spawning and score increase
* Snake growth on eating food
* Game over on wall or self collision
* Simple and lightweight implementation

---

## 🛠️ Tech Stack
* Programming Language: **Python**
* Library / Framework: **Standard library / minimal dependencies**
* Platform: **Desktop**

---

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* Python **3.10+** installed

Check your version:

```bash
python --version
```

---

### Installation

Clone the repository:

```bash
git clone git@github.com:KeannenHalim/playground-snake-game.git
cd playground-snake-game
```

(Optional) Create a virtual environment:

```bash
python -m venv venv
source venv/bin/activate  # macOS / Linux
venv\Scripts\activate     # Windows
```

---

### Run the Game

```bash
python main.py
```
